## 🚀 Overview

**RePrompt** is an AI-powered developer and creator tool that turns visual inspiration into structured, high-performance prompts. By leveraging advanced multimodal vision capabilities, it analyzes composition, lighting, style, subject matter, and color grading from any uploaded image, formatting the output precisely for the syntax requirements of top-tier AI engines.

---

## 🌟 Key Features

* **Multi-Model Optimization:** Generates tailored prompts optimized for specific engine architectures:
  * **Midjourney v7** (Stylized parameters, aspect ratios, aesthetic weighting)
  * **FLUX 1.1 Pro** (Natural language descriptive depth, realism cues)
  * **Stable Diffusion 3.5 Large** (Token-optimized structure, modifier balance)
  * **Gemini** (Multimodal contextual understanding and detailed breakdowns)
* **Drag-and-Drop Interface:** Clean, modern UI with instant image preview and processing states.
* **One-Click Copy:** Quickly copy formatted prompt blocks to your clipboard.
* **Responsive Design:** Fully optimized for desktop and mobile workflows.
